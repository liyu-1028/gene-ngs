# gene-ngs: V2 reproducibility code for synthetic clinical records and simulated FASTQ reads

This repository provides the code and documentation supporting Version 2 (V2) of the **Synthetic MSK-IMPACT 2017 cohort: audited clinical-variant tables and simulated FASTQ reads from a hybrid generative pipeline** dataset.

## Release state

The ScienceDB record is [10.57760/sciencedb.0131a](https://doi.org/10.57760/sciencedb.0131a). Version 1 is public. Version 2 has been submitted to ScienceDB for platform review. V2 adds the stable record index, explicit CSV-row-to-FASTQ mapping, classified simulator-input specifications, quality flags, corrected analyses, archive audit, bounded public-read recount, figure data and a V2 manifest. It must not be described as publicly approved until ScienceDB completes its review.

`gene-ngs-v2.0.0-source.tar.gz` is the frozen source bundle for the V2 manuscript and data release. Its SHA-256 is recorded in [V2_CODE_RELEASE.md](V2_CODE_RELEASE.md). The bundle includes the metadata reconstruction, corrected analysis, manuscript-table and figure preparation, archive audit, selected 21-mer recount and release-gate scripts. The V2 package also contains the smaller `v2_verification_code.tar.gz` bundle used to verify a downloaded dataset.

## What the V2 code can verify

- The frozen 10,328-row CSV is indexed by `synthetic_record_id`; 2,000 rows map explicitly to 2,000 FASTQ archive members.
- The retained V1 FASTQ tar passed an independent full-archive audit: archive checksum, member paths and MD5s, gzip integrity, FASTQ structure, 200,000 reads per member and 100-base read length.
- A bounded independent 21-mer recount matched all 183 selected anchor pairs with distinguishable REF and ALT contexts. It is not an all-variant calling benchmark.
- Corrected analyses withdraw the former zero-exact-match, zero-distance privacy and membership-inference claims. The discriminator is a real-versus-synthetic classifier, and DCR/NNDR are descriptive diagnostics rather than a privacy guarantee.

The historical generator cannot be regenerated byte-for-byte from this repository: the exact reference FASTA, target BED, simulator model files, executable and high-depth mini-simulation reads are unavailable. The V2 data and documentation label these limits explicitly.

## Quick start

Download the V2 dataset through ScienceDB, extract `gene-ngs-v2.0.0-source.tar.gz`, and install the pinned quick-check requirements:

```bash
tar -xzf gene-ngs-v2.0.0-source.tar.gz
cd gene-ngs-v2.0.0-source
python3 -m pip install -r requirements-v2-quick.txt
python3 scripts/check_v2_release_candidate.py \
  --candidate /path/to/V2 \
  --cohort /path/to/synthetic_msk_impact_2017_cohort.csv \
  --archive-report /path/to/FASTQ_ARCHIVE_AUDIT.json \
  --read-check /path/to/INDEPENDENT_ANCHOR_READ_CHECK.json \
  --output ./V2_CANDIDATE_GATE.json
```

See [docs/reproducibility.md](docs/reproducibility.md) for inputs, commands, scope and limitations. The release DOI should be cited only after the submitted V2 version has been approved and its public download has passed the manifest check.
