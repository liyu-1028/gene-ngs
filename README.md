# gene-ngs — Synthetic Cancer NGS Cohort Generation Pipeline

A reproducible five-stage pipeline that generates **synthetic matched clinical–variant
datasets with physically simulated FASTQ reads** for cancer genomics benchmarking.

The pipeline was used to produce two synthetic cohorts derived from MSK-IMPACT
(Zehir et al., *Nat Med* 2017):

| Cohort | Records | FASTQ | Depth |
|---|---|---|---|
| msk_impact_2017-derived | 10,328 patients | 2,000 patients × 200,000 single-end 100 bp reads | 0.2× WES |
| msk_impact_50k-derived (verification only) | 51,010 patients | — | — |

## Pipeline overview

```
Stage 1  Data governance        Real cohort ingestion, schema mapping, provenance
Stage 2  Tabular generation     CTGAN-based synthetic clinical/variant tables
Stage 3  Clinical audit         Hard rules + LLM-assisted plausibility screening
Stage 4  Read simulation        synggen biophysical FASTQ simulation (seeded)
Stage 5  Technical validation   Statistical fidelity · TSTR utility · privacy · VAF recovery
```

Key design decisions:

* **Determinism** — every simulated patient uses `seed = 42 + patient_index`;
  the entire 4,000-file corpus is bit-reproducible given the same reference inputs.
* **Clinical realism** — generated tables pass a rule-based + LLM audit
  (`audit_stage` column records the passing stage).
* **Physical grounding** — reads are produced by [synggen](https://bitbucket.org/CibioBCG/synggen)
  (Bioinformatics 2023) against GRCh38 full analysis set + decoy + HLA, not by
  shuffling strings, so alignment-based downstream tools behave as with real data.
* **Honest privacy reporting** — membership-inference AUC ≈ 0.68 is reported as a
  caution for ML reuse rather than hidden.

## Technical validation summary

| Metric | 2017-derived cohort | 50K cohort |
|---|---|---|
| TMB distribution (KS) | 0.115 | 0.090 |
| Gender (TV distance) | 0.113 | 0.080 |
| Top-30 gene frequency TVD | 0.036–0.139 | 0.080 |
| TRTR / TSTR AUC | 0.791 / 0.425 | 0.751 / **0.565** |

`src/stage0` mixes pipeline entry points with one-off operational scripts used
during corpus production (resume/flatten/verify/manifest helpers); each script
has a header comment describing its role.

## Reproducing

**Start with [`docs/reproducibility.md`](docs/reproducibility.md)** — it contains the
complete, verified recipe: pinned Python environment, synggen build instructions,
reference-data sources, per-stage commands with inputs/outputs, environment
variables, determinism guarantees and the expected validation numbers.

```bash
python3.10 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # exact verified versions (see requirements.txt)
cp .env.example .env                     # only if you enable the Stage 3 LLM audit
python src/stage5/statistical_fidelity.py REAL.csv SYN.csv   # e.g. validate a cohort
```

Quick sanity check that your synggen build works (one virtual patient,
200,000 reads, 0.2× WES) is included in the reproducibility guide.
